Accessibilite

Derniere mise a jour : Janvier 2026

Schnock s'engage a garantir l'accessibilite numerique pour les personnes en situation de handicap. Nous ameliorons continuellement l'experience utilisateur pour tous et appliquons les normes d'accessibilite en vigueur.

Etat de conformite

Ce site web est conforme aux WCAG 2.1 Niveau AA (Regles pour l'accessibilite des contenus Web). Ces regles expliquent comment rendre le contenu web plus accessible aux personnes handicapees et plus convivial pour tous.

Le site web est conforme aux exigences de la Loi europeenne sur l'accessibilite (EAA), entree en vigueur le 28 juin 2025.

Fonctionnalites d'accessibilite

Ce site web comprend les fonctionnalites d'accessibilite suivantes :

  • Navigation au clavier : Toutes les fonctionnalites sont accessibles via le clavier, y compris les menus de navigation, les formulaires et les elements interactifs.
  • Lien d'evitement : Un lien "Aller au contenu principal" permet aux utilisateurs de clavier de contourner la navigation repetitive.
  • Support des lecteurs d'ecran : Des attributs ARIA et des roles appropries assurent la compatibilite avec les technologies d'assistance.
  • Indicateurs de focus : Des etats de focus visibles aident les utilisateurs de clavier a suivre leur position sur la page.
  • Accessibilite des formulaires : Tous les champs de formulaire ont des libelles associes et des messages d'erreur clairs.
  • Texte alternatif : Les images incluent un texte alternatif descriptif ou sont marquees comme decoratives.
  • Structure des titres : Une hierarchie logique des titres aide les utilisateurs a naviguer dans le contenu.
  • Mouvement reduit : Les animations respectent le parametre "prefers-reduced-motion" de l'utilisateur.

Limitations connues

Bien que nous nous efforcions d'atteindre une conformite totale en matiere d'accessibilite, certaines limitations peuvent exister :

  • Contraste des couleurs : Les restaurateurs peuvent personnaliser les couleurs. Les modeles par defaut respectent les exigences de contraste, mais les couleurs personnalisees sont sous la responsabilite de chaque restaurant.
  • Contenu tiers : Certains contenus integres provenant de services externes peuvent ne pas etre entierement accessibles.
